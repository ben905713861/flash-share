# Flash Share

Flash Share lets you pair two devices and share text or files directly, without uploading them to a central service.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

The app uses Expo Router file-based routing. The main screen is in `src/app/index.tsx`.

### Tauri desktop updates

Tauri release bundles include signed updater artifacts. Keep the private signing key in `react_native/.tauri/` or provide it through `TAURI_SIGNING_PRIVATE_KEY` and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`; never commit it. The public key and updater endpoint are configured in `src-tauri/tauri.conf.json`.

Build a release with `npm run tauri-build` after setting the signing environment variables. Publish the generated `latest.json` and platform installer artifacts at the configured endpoint. Desktop clients check for updates when the app starts, install an available update, and relaunch automatically.

GitHub releases are generated by the repository workflow at `../.github/workflows/tauri-release.yml` when a `v*` tag is pushed. Add the repository secrets `TAURI_SIGNING_PRIVATE_KEY` and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`, then create a release with `git tag v1.0.1 && git push origin v1.0.1`. The workflow builds Linux, Windows, and macOS artifacts and publishes the updater metadata to the GitHub Release.

# Local Android release signing

The Android release signing config reads the same `credentials.json` structure used by EAS local credentials. Copy `credentials.example.json` to `credentials.json`, fill in the Android keystore fields, and place the keystore at the configured path. Relative keystore paths are resolved from the `react_native` directory. Both `credentials.json` and `*.jks` files are ignored by Git.

Then run `npm run android-local-build`. The Expo prebuild config plugin applies the credentials to the generated Gradle release signing config.
