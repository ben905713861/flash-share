# Flash Share UI

## 页面骨架

- 根节点使用安全区和可滚动容器，内容居中并限制最大宽度。
- 顶部栏左侧为 Flash Share 品牌标记，右侧为连接状态、主题切换和退出按钮。
- 顶部栏下方显示绿色连接状态点。

## 页面状态

- **配对页**：标题“Pair a device!”，展示本机配对二维码和配对码；下方提供另一台设备配对码输入框与 Pair 按钮。
- **等待/连接页**：居中的加载指示器、等待标题和说明；加入房间后额外展示本机二维码。
- **工作区**：Text / File 两个标签。Text 标签展示多行消息输入框、字符数和发送按钮；File 标签展示文件选择区域、传输进度列表、准备状态和发送按钮。
- **接收弹窗**：半透明遮罩上的对话框，列出收到的文件，并提供 Decline 与 Choose folder & receive 操作。

## 视觉规则

- 页面背景和面板颜色随系统主题切换。
- 面板使用细边框、小圆角和紧凑间距；主操作使用蓝色，次操作使用描边按钮。
- 文件进度使用横向进度条，文件名单行截断，状态和大小使用弱化文字。
